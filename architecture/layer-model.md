# Layer Model

Authority and dependency flow:

1. `direction` -> informs
2. `architecture` -> defines internal model
3. `core` -> implements primitives
4. `profiles` -> specialize domains without redefining core
5. `decisions` -> freeze contentious boundaries
6. `research` -> explores, does not govern
7. `roadmap` -> plans evolution

No lower layer may redefine a higher one.
