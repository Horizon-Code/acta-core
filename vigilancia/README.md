# Vigilancia semanal

Esta carpeta es una bandeja neutral de cambios. El recolector nunca escribe hallazgos, niveles,
preguntas de investigación ni enmiendas. Una sesión humana decide si una entrada asciende al
cerebro de ACTA.

- `state.json` contiene únicamente cursores, contadores y hashes para comparar ejecuciones.
- `AAAA-Www.md` es el informe de una semana ISO.
- Una semana sin entradas es un resultado válido.
- Un error o una fuente no configurada aparece siempre en el informe.

Implementación y configuración: [`tools/vigilancia/`](../tools/vigilancia/).
