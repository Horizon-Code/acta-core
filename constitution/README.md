# Constitution

Highest-authority internal ACTA texts.

## Purpose

`constitution/` contains ACTA's own constitutional foundations. This is the top of the repository authority hierarchy.

## Authority

Authority order used in this repository:

1. `constitution/`
2. `architecture/`
3. `direction/`
4. `core/`
5. `profiles/`
6. `decisions/`
7. `research/`
8. `roadmap/`

No lower level may redefine a higher level.

## Binding rule

External or directional ideas become binding only when explicitly rewritten under `constitution/`, `architecture/`, or `decisions/`.
